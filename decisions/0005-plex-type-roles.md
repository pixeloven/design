# DDR-0005: Plex Sans for task text, Plex Mono for identifiers and data

**Status:** accepted · **Date:** 2026-10-23, first written in the brand-family guide.
**Backfilled** on 2026-11-21. This record adds no new content.

## Decision

> Plex Sans carries human task text. Plex Mono distinguishes identifiers, code
> and measured data. Readable roles take priority over compact metadata styling.
>
