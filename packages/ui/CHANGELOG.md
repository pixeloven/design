# Changelog

## 0.1.0

- Add native React 19 Button, Input, Select and Label components with typed
  native props and DOM refs. Buttons default to a non-submitting action.
- Extract readable, accessible control states into scoped CSS using the tokens
  0.6 theme contract. Consumers choose themes, load fonts and import CSS.
- Publish ESM and declarations with explicit React and token peers; verify
  native forms, keyboard focus and packed consumer imports and public types.
