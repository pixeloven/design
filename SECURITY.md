# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability
reporting: open this repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue, pull request or discussion for a
security problem.

Include the affected package (`@pixeloven/tokens`, `@pixeloven/brand`,
`@pixeloven/ui` or the docs image), its version, and steps to reproduce.

## Supported versions

Each package is released independently from `main` (tags such as
`tokens-v0.6.0`). Fixes land on `main` and ship in a new release of the
affected package; only the latest release of each package is supported.
Older versions do not get backported fixes.
